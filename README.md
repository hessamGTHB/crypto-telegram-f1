# 🤖 ربات قیمت ارز دیجیتال برای کانال تلگرام

ربات پایتونی که به‌صورت **خودکار هر ساعت** قیمت لحظه‌ای ارزهای دیجیتال را از **CoinGecko** می‌گیرد و با قالب ایموجی‌دار و جدولی در کانال شما منتشر می‌کند. رابط ربات و پست‌ها از **۶ زبان** پشتیبانی می‌کنند.

## ✨ امکانات

- ⏰ ارسال خودکار هر ۱ ساعت (قابل تغییر بین ۱۰ تا ۱۴۴۰ دقیقه با `/interval`)
- 📊 قالب پست ایموجی‌دار: قیمت، درصد تغییر ۲۴ ساعته با 🟢/🔴 و مارکت کپ کل
- 🪙 لیست ارزهای **قابل تنظیم** با `/addcoin` و `/delcoin` (جستجوی نام یا نماد، مثلاً `/addcoin BTC`)
- 🌐 چندزبانه: **فارسی، انگلیسی، چینی، ژاپنی، کره‌ای و هندی** — هم برای رابط ربات و هم برای زبان پست کانال
- 📅 تاریخ پست‌های فارسی با **تقویم جلالی** و اعداد فارسی
- 💾 تنظیمات در فایل JSON ذخیره می‌شود؛ بدون نیاز به دیتابیس
- 📡 منبع قیمت: CoinGecko (رایگان، بدون کلید — کلید API اختیاری هم پشتیبانی می‌شود)

## 📁 ساختار پروژه

```
telegram-crypto-bot/
├── bot.py            # نقطه ورود و راه‌اندازی ربات

├── prices.py         # کلاینت CoinGecko (با تلاش مجدد خودکار)
```

## 🚀 راه‌اندازی سریع

### ۱) ساخت ربات

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید
2. دستور `/newbot` را بزنید و نام و یوزرنیم ربات را انتخاب کنید
3. توکن (شبیه `123456789:AAAA...`) را کپی کنید

آی‌دی عددی تلگرام خودتان را هم از [@userinfobot](https://t.me/userinfobot) بگیرید.

### ۲) ادمین‌کردن ربات در کانال

ربات را به‌عنوان **ادمین کانال** اضافه کنید و دسترسی **Post Messages** را فعال کنید. بدون این دسترسی ربات نمی‌تواند در کانال پست بگذارد.

### ۳) تنظیم `.env`

```bash
cd telegram-crypto-bot
cp .env.example .env
nano .env    # یا هر ویرایشگر دیگر
```

حداقل این دو مقدار را پر کنید:

```env
BOT_TOKEN=123456789:AAAA-your-token-here
ADMIN_IDS=123456789
```

> ⚠️ اگر `ADMIN_IDS` خالی بماند، هر کسی در چت خصوصی عملاً مدیر ربات است. حتماً آی‌دی خودتان را وارد کنید.

### ۴) نصب و اجرا

نیاز به **Python 3.10+** دارد:

```bash
python3 -m venv venv
source venv/bin/activate      # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

یا خلاصه‌تر روی لینوکس: `bash run.sh`

### ۵) تنظیم کانال از داخل ربات

در چت خصوصی با ربات:

```
/channel @نام_کانال_شما
```

ربات یک پیام آزمایشی می‌فرستد و حذف می‌کند تا مطمئن شود دسترسی دارد؛ سپس تنظیمات ذخیره می‌شود. همین حالا اولین پست حدود ۲۵ ثانیه بعد به‌صورت خودکار ارسال می‌شود. 🎉

## 🧭 دستورات

| دستور | دسترسی | کار |
|---|---|---|
| `/start` | همه | شروع + انتخاب زبان |
| `/help` | همه | راهنما |
| `/lang` | همه | تغییر زبان (مدیر = زبان پست کانال هم عوض می‌شود) |
| `/post` | مدیر | ارسال فوری پست قیمت به کانال |
| `/coins` | مدیر | نمایش لیست فعلی ارزها |
| `/addcoin bitcoin` | مدیر | افزودن ارز (با نام، آی‌دی یا نماد: `BTC`, `SOL`, `TON`) |
| `/delcoin bitcoin` | مدیر | حذف ارز |
| `/channel @name` | مدیر | تنظیم/تغییر کانال مقصد |
| `/interval 60` | مدیر | فاصله ارسال خودکار به دقیقه (۱۰ تا ۱۴۴۰) |
| `/status` | مدیر | نمایش تنظیمات فعلی |

نمونه `/addcoin`: اگر عبارت مبهم باشد (مثلاً چند ارز با یک نماد)، ربات لیستی از گزینه‌ها با دکمه شیشه‌ای نشان می‌دهد تا انتخاب کنید.

## 🌐 مدیریت زبان‌ها

- هر کاربر با `/lang` زبان رابط خودش را انتخاب می‌کند.
- اگر **مدیر** زبانی را انتخاب کند، زبان **پست‌های کانال** هم عوض می‌شود.
- زبان پیش‌فرض از `DEFAULT_LANGUAGE` در `.env` خوانده می‌شود.

### افزودن زبان جدید

1. در `i18n.py` کد زبان و برچسب پرچم‌دار را به `LANGUAGES` اضافه کنید:
   ```python
   LANGUAGES = {..., "ar": "🇸🇦 العربية"}
   ```
2. دیکشنری `TEXTS["en"]` را کپی کنید، به `"ar"` تغییر نام دهید و ترجمه کنید (جای `{placeholders}` را نگه دارید).
3. کد زبان را به `SUPPORTED_LANGUAGES` در `config.py` اضافه کنید.
4. (اختیاری) نام بومی ارزها را در `COIN_NAMES` کامل کنید.

## 🖥 استقرار دائمی

### systemd (سرور لینوکسی — پیشنهادی)

```bash
sudo cp -r telegram-crypto-bot /opt/crypto-channel-bot
cd /opt/crypto-channel-bot
python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
sudo cp deploy/crypto-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now crypto-bot
journalctl -u crypto-bot -f     # مشاهده لاگ
```

### Docker

```bash
docker build -t crypto-bot .
docker run -d --name crypto-bot --restart always \
  --env-file .env \
  -v $(pwd)/data:/app/data \
  crypto-bot
```

### screen / tmux (ساده)

```bash
screen -S cryptobot
source venv/bin/activate && python bot.py
# خروج با Ctrl+A سپس D
```

## ⚠️ نکته‌ها و رفع اشکال

| مشکل | راه‌حل |
|---|---|
| ربات در کانال پست نمی‌فرستد | ربات باید **ادمین کانال** با دسترسی Post Messages باشد؛ بعد دوباره `/channel @name` را بزنید |
| خطای `Channel private` | یوزرنیم کانال را با `/channel` درست وارد کنید یا آی‌دی عددی کانال (`-100...`) بدهید |
| خطای `429` از CoinGecko | فاصله ارسال را با `/interval` بیشتر کنید (۱۵ دقیقه به بالا) یا کلید API در `.env` بگذارید |
| مدیریتی کار نمی‌کند | آی‌دی عددی خودتان را در `ADMIN_IDS` بگذارید و ربات را ری‌استارت کنید |
| قیمت ارزی نمایش داده نمی‌شود | آن ارز در CoinGecko موجود نیست؛ با `/delcoin` حذف و ارز دیگری اضافه کنید |

**محدودیت نرخ:** API رایگان CoinGecko حدوداً ۵ تا ۳۰ درخواست در دقیقه مجاز است. هر پست فقط ۲ درخواست مصرف می‌کند (قیمت‌ها + مارکت کپ کل)، پس ارسال هر ۱۰ تا ۱۵ دقیقه کاملاً امن است.
